# CKA source migration

This repository is the consolidated CKA learning workspace. Useful content was
absorbed from `cka-qa`, `cka-lab-notes`, `learning-lab`, and `cka-shared`.
The source repository histories remain in the Git object database through
migration commits; the working tree is now organized by purpose.

## Boundaries

- `qa/`: theory, recall, status, and weak-topic tracking.
- `notes/`: troubleshooting guides and kubectl cheatsheets.
- `exercises/`: practical build/break/fix drills.
- `labs/debug-labs/`: Docker/debug learning labs and reports.
- `docs/cka-shared/`: inlined handoff state and workflow guidance.
- `scripts/`: small helper scripts for the learning workspace.
